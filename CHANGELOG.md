# Changelog

Все значимые изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.2.0-alpha] - 2026-11-10

Успешно реализован консольный парсер бинарного потока данных и проверена совместимость CRC.

### Добавлено (Added)

- Скрипт `parser_console.py` (в `src/backend/`), читающий COM-порт, разбирающий UART-фреймы и проверяющий CRC.
- Алгоритм проверки CRC-16/CCITT-FALSE на Python (100% совместимость с прошивкой ESP32).
- Отчет об испытаниях (`artifacts/reports/report-stage-2-parser.md`).
- Логи прогона парсера (`artifacts/reports/logs/`).

### Изменено (Changed)

- Прошивка `master.ino` переведена из режима отладки в «боевой» режим: текстовый HEX-вывод заменен на передачу реальных бинарных байтов (`Serial.write()`).

## [0.1.0-alpha] - 2026-11-09

Первая успешная веха. Отладка связи между двумя ESP32 и подготовка к интеграции с сервером.

### Добавлено (Added)

- Прошивка `master.ino` (Хаб): реализован опрос узла по ESP-NOW и упаковка данных в UART-фрейм с расчетом CRC-16/CCITT-FALSE.
- Прошивка `slave.ino` (Узел): реализован ответ на `REQ` и генерация тестовых данных (заглушка).
- Отчет об испытаниях (`artifacts/reports/report-stage-1-mcu.md`).
- Логи успешных прогонов (`artifacts/reports/logs/`).
- Файл дорожной карты проекта (`ROADMAP.md`).

### Изменено (Changed)

- Исправлена ошибка компиляции в ESP32 Core v3.x (замена типа аргумента в `OnDataRecv` на `esp_now_recv_info_t`).
- Исправлена проблема с получением MAC-адреса (замена `WiFi.macAddress()` на `esp_read_mac()`).
