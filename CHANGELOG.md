# Changelog

Все значимые изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.4.0-alpha] - 2026-11-10

Реализована двусторонняя неблокирующая связь. Система теперь поддерживает отправку команд.

### Добавлено (Added)

- Прошивка Узла: неблокирующая обработка команды `led` на основе `millis()`.
- Прошивка Хаба: распаковка UART-фреймов для извлечения команд и отправка их по ESP-NOW.
- `parser.py`: фоновый TCP-сервер для приема команд извне (порт 65432).
- Скрипт `send_cmd.py` для отправки команд из отдельного терминала.
- Отчет об испытаниях (`artifacts/reports/report-stage-4-cmd-ack.md`).

### Изменено (Changed)

- Логика `loop()` Узла теперь проверяет таймер светодиода, не блокируя прием запросов `REQ`.
