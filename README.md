# ESP32-Network: Система сбора и хранения телеметрических данных

Проект представляет собой распределенную микроконтроллерную систему сбора телеметрии на базе ESP32 (WROOM-32), работающую по протоколу ESP-NOW, с последующей передачей данных по UART на сервер (Raspberry Pi / ПК) и сохранением в реляционную базу данных.

Система спроектирована с учетом строгих требований Технического Задания (ТЗ), но при этом использует современные паттерны отказоустойчивой архитектуры (Schema Registry, асинхронный опрос, гибридное хранение JSONB).

## 🚀 Ключевые особенности

- **Протокол ESP-NOW:** Энергоэффективная передача данных от узлов к концентратору.
- **Асинхронный опрос (Non-blocking Polling):** Концентратор не зависает при потере связи с одним из узлов.
- **Schema Registry:** Поддержка версионирования протоколов и гибкое добавление новых датчиков без миграций базы данных.
- **Гибридное хранение (JSONB):** PostgreSQL используется как Single Source of Truth (SSOT).
- **Разделение BFF (Backend for Frontend):** Парсер (демон) работает независимо от веб-интерфейса.

## 🛠️ Технологический стек

- **Микроконтроллеры:** ESP32-WROOM-32 (C++ / Arduino Framework)
- **Радиопротокол:** ESP-NOW
- **Серверная часть:** Python 3.11+ (плюс библиотеки `pyserial`, `psycopg`)
- **База данных:** PostgreSQL (с поддержкой JSONB)
- **Интерфейс:** FastAPI + Jinja2/HTMX или Streamlit (для MVP)

## ⚡ Быстрый старт (MVP)

Для запуска базового прототипа (ПК на Windows 10, ESP32 подключены по USB):

### 1. Подготовка базы данных

Установите PostgreSQL и создайте базу данных `iot`. Примените скрипты из `src/db/`:

```powershell
psql -U postgres -c "CREATE DATABASE iot;"
psql -U postgres -d iot -f src/db/schema.sql
```

### 2. Запуск серверной части

Установите зависимости и запустите парсер:

```powershell
cd src/backend
pip install -r requirements.txt
python parser.py
```

### 3. Запуск веб-интерфейса

В отдельном терминале запустите дашборд (например, на Streamlit):

```powershell
cd src/frontend
streamlit run app.py
```

### 4. Прошивка ESP32

1. Откройте `src/mcu/master/master.ino` и `src/mcu/slave/slave.ino` в Arduino IDE.
2. Установите библиотеки `DHT sensor library` и `Adafruit Unified Sensor`.
3. Прошейте концентратор (узнайте его MAC-адрес из Serial Monitor).
4. Впишите MAC-адрес концентратора в скетч `slave.ino` и прошейте узел.
5. Подайте питание. Данные начнут поступать в базу.
