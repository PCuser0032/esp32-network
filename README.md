# ESP32-Network: Система сбора и хранения телеметрических данных

Проект представляет собой распределенную микроконтроллерную систему сбора телеметрии на базе ESP32 (WROOM-32), работающую по протоколу ESP-NOW, с последующей передачей данных по UART на сервер (ПК / Raspberry Pi), сохранением в реляционную базу данных и возможностью удаленного управления устройствами (команды CMD/ACK).

Система спроектирована с учетом строгих требований Технического Задания (ТЗ), но при этом использует современные паттерны отказоустойчивой архитектуры (бинарный UART-фрейминг с проверкой CRC, паттерн «Репозиторий» для работы с БД, неблокирующая логика на микроконтроллерах).

## 🚀 Ключевые особенности

- **Протокол ESP-NOW:** Энергоэффективная передача данных от узлов к концентратору.
- **Бинарный UART-фрейминг:** Передача данных от Хаба к серверу с защитой от помех (байты `0xAA`/`0x55` и контрольная сумма CRC-16/CCITT-FALSE).
- **Двусторонняя связь (CMD/ACK):** Возможность отправки внеплановых команд с сервера на узлы (например, включение светодиода) с подтверждением выполнения.
- **Неблокирующая логика (MCU):** Узлы выполняют команды, не прерывая основной цикл сбора данных (используется `millis()` вместо `delay()`).
- **Абстракция БД (Repository Pattern):** Код парсера не зависит от конкретной СУБД. Сейчас используется SQLite для MVP, в планах — PostgreSQL с JSONB.
- **Разделение ввода-вывода:** Логи пишутся в основной поток, а команды отправляются через локальный TCP-сокет (утилита `send_cmd.py`), что готовит систему к интеграции с веб-интерфейсом.

## 🛠️ Технологический стек

- **Микроконтроллеры:** ESP32-WROOM-32 (C++ / Arduino Framework)
- **Радиопротокол:** ESP-NOW
- **Серверная часть:** Python 3.11+ (библиотеки `pyserial`, встроенный `socket`)
- **База данных:** SQLite (текущая для MVP) / PostgreSQL (целевая с JSONB)
- **Интерфейс:** Streamlit (в планах)

## ⚡ Быстрый старт

Для запуска прототипа (ПК, ESP32 подключены по USB):

### 1. Настройка окружения

```powershell
cd src/backend
pip install -r requirements.txt
```

_(База данных SQLite `iot.db` создастся автоматически при первом запуске парсера)._

### 2. Запуск парсера (Терминал 1)

Запустите основной скрипт, который будет читать COM-порт, писать в БД и слушать TCP-порт для команд:

```powershell
python parser.py
```

_Не забудьте указать ваш COM-порт в переменной `SERIAL_PORT` внутри `parser.py`._

### 3. Отправка команд (Терминал 2)

Пока первый терминал выводит логи, откройте второй и отправьте команду на включение светодиода (например, на 2 секунды):

```powershell
python send_cmd.py "CMD 01 101 led 2000"
```

_В первом терминале вы увидите отправку и получение ACK, а на ESP32 загорится светодиод._

### 4. Прошивка ESP32

1. Откройте `src/mcu/master/master.ino` и `src/mcu/slave/slave.ino` в Arduino IDE.
2. Прошейте концентратор (узнайте его MAC-адрес из Serial Monitor).
3. Впишите MAC-адрес концентратора в скетч `slave.ino` и прошейте узел.
4. Подайте питание.
