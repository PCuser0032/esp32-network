# ESP32-Network: Система сбора и хранения телеметрических данных

Проект представляет собой распределенную микроконтроллерную систему сбора телеметрии на базе ESP32 (WROOM-32), работающую по протоколу ESP-NOW, с последующей передачей данных по UART на сервер (ПК / Raspberry Pi) и сохранением в реляционную базу данных.

Система спроектирована с учетом строгих требований Технического Задания (ТЗ), но при этом использует современные паттерны отказоустойчивой архитектуры (Schema Registry, асинхронный опрос, гибридное хранение JSONB, бинарный UART-фрейминг с проверкой CRC).

## 🚀 Ключевые особенности

- **Протокол ESP-NOW:** Энергоэффективная передача данных от узлов к концентратору.
- **Бинарный UART-фрейминг:** Передача данных от Хаба к серверу с защитой от помех (байты `0xAA`/`0x55` и контрольная сумма CRC-16/CCITT-FALSE).
- **Асинхронный опрос (Non-blocking Polling):** Концентратор не зависает при потере связи с одним из узлов _(в планах)_.
- **Schema Registry:** Поддержка версионирования протоколов и гибкое добавление новых датчиков без миграций базы данных _(в планах)_.
- **Гибридное хранение (JSONB):** PostgreSQL используется как Single Source of Truth (SSOT).

## 🛠️ Технологический стек

- **Микроконтроллеры:** ESP32-WROOM-32 (C++ / Arduino Framework)
- **Радиопротокол:** ESP-NOW
- **Серверная часть:** Python 3.11+ (библиотеки `pyserial`, `psycopg`)
- **База данных:** PostgreSQL (с поддержкой JSONB)
- **Интерфейс:** FastAPI + Jinja2/HTMX или Streamlit

## ⚡ Быстрый старт

### 1. Подготовка базы данных (в разработке)

_Раздел будет дополнен после завершения интеграции с PostgreSQL._

```powershell
psql -U postgres -c "CREATE DATABASE iot;"
psql -U postgres -d iot -f src/db/schema.sql
```

### 2. Запуск парсера (Текущий этап)

Скрипт читает COM-порт, ищет UART-фреймы и проверяет CRC.

```powershell
cd src/backend
pip install pyserial
python parser.py
```

### 3. Прошивка ESP32

1. Откройте `src/mcu/master/master.ino` и `src/mcu/slave/slave.ino` в Arduino IDE.
2. Прошейте концентратор (узнайте его MAC-адрес из Serial Monitor).
3. Впишите MAC-адрес концентратора в скетч `slave.ino` и прошейте узел.
4. Подайте питание. Данные начнут поступать на сервер.
