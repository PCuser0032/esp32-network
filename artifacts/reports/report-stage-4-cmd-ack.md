# Отчет об испытаниях: Этап 4 (Обратный поток CMD/ACK)

**Дата:** 2026-11-10
**Статус:** ✅ Успешно завершено
**Расположение артефактов:** `sandbox/stage-4/`

## 1. Цель этапа

Реализовать двустороннюю связь. Проверить возможность отправки внеплановых команд (на примере мигания встроенного светодиода) от сервера (ПК) через Хаб к Узлу. Убедиться, что выполнение команды не блокирует плановый опрос (телеметрию).

## 2. Методика испытаний

1. **Развязка интерфейсов:** Для удобства работы ввод команд был вынесен в отдельный TCP-сокет (`127.0.0.1:65432`). Скрипт `parser.py` слушает порт, а утилита `send_cmd.py` отправляет команды.
2. **Неблокирующая логика (Узел):** При получении команды `led` Узел не использует `delay()`. Он запоминает время старта и включает светодиод. Выключение происходит в функции `loop()` при достижении заданного интервала.
3. **Протокол:** Сервер шлет строку `CMD 01 101 led 3000`, где `101` — ID команды, а `3000` — длительность свечения в мс. Узел обязан ответить `ACK 01 101 OK`.

## 3. Результаты испытаний

### 3.1. Доказательство неблокирующего поведения (Лог Узла)

Светодиод был включен на 3000 мс, но Узел продолжал штатно отвечать на запросы Хаба, не пропуская циклы телеметрии.

```text
[Фрагмент лога stage-4-output-slave-1.txt]
20:42:16.290 -> RX CMD: CMD 01 101 led 3000
20:42:16.290 -> Action: LED ON for 3000 ms
20:42:16.290 -> TX: ACK 01 101 OK
20:42:16.509 -> TX: TLM 01 sensors 61 v1 23.1 50.5  <-- Телеметрия пришла во время горения LED!
20:42:19.276 -> Action: LED OFF                       <-- Светодиод выключился ровно через 3 секунды.
```

### 3.2. Работа TCP-сервера и ACK (Лог Парсера)

Команды успешно принимаются из второго терминала и отправляются в порт. Подтверждения доходят до сервера.

```text
[Фрагмент лога stage-4-output-parser-2.txt]
20:42:06 ... (телеметрия)
[>>>] Отправлено в порт: CMD 01 101 led 1000
[<<<] Получен ACK: ACK 01 101 OK
20:42:11 [+] DB Save OK | 01 | {'temperature': 23.6, 'humidity': 64.4}
[>>>] Отправлено в порт: CMD 01 101 led 3000
[<<<] Получен ACK: ACK 01 101 OK
20:42:16 [+] DB Save OK | 01 | {'temperature': 23.1, 'humidity': 50.5}
```

## 4. Выводы

1. **Архитектура двусторонней связи работоспособна.** Команды доходят от Python до Узла без задержек.
2. **Неблокирующий подход полностью решает проблему «зависаний».** Узел выполняет действия, не прерывая основной цикл сбора данных.
3. **TCP-развязка успешна.** Ввод команд больше не мешает чтению логов и позволяет в будущем легко подключить веб-интерфейс.
